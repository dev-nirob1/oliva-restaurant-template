# Oliva – restaurant HTML template (CDN version)
Structure: index.html (root), pages/ (about, menu, gallery, blog, blog-details, contact, reservation, product, cart), assets/css, assets/js, assets/images.
Open index.html (internet needed: Tailwind v4 browser CDN, Preline, Swiper, AOS, Remix Icon, Google Fonts, Unsplash photos).
- Theme + component classes: inline <style type="text/tailwindcss"> in each page head (CDN mode). Same code is ready in assets/css/input.css for the Tailwind CLI.
- Other CSS: assets/css/style.css. Menu data: assets/js/app.js (array M). Cart/order use localStorage; forms are front-end only.
